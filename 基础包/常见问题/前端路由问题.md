## Vue Router warn]: No match found for location with path "/xxx"

Vue Router 维护者 [posva 在 issue #1131](https://github.com/vuejs/vue-router-next/issues/1131) 里写得很直白：

> The message you see is just a warning to allow people to detect typos and can be safely ignored.
> You can also make sure to add your routes before starting the app— `app.use(router)` is what triggers the router to start.

也就是说：警告是「当前 URL 在路由表里还匹配不到」的提示，不是导航失败；动态路由场景下接受这种噪音。
