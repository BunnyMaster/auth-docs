## Vue Router warn: No match found for location with path "/xxx"

首屏 `app.use(router)` 时路由表里只有静态路由（`modules/` + `remaining`）。后端动态路由要等登录后或冷启动守卫里 `initRouter` → `addRoute` 才挂上。直开业务 path 时，首轮匹配失败就会刷这条 warn。

Vue Router 维护者 [posva 在 issue #1131](https://github.com/vuejs/vue-router-next/issues/1131) 里说得很直白：这是「当前 URL 在表里还匹配不到」的提示，**不是导航失败**；动态路由时序下可以当噪音。

**别一律无视**：`initRouter` 跑完后仍 No match，才是真问题——菜单没配、组件路径对不上、或 path 写错。
