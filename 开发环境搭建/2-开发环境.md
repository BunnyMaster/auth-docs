## 系统环境

> [!IMPORTANT]
>
> - 系统装机与版本支持以 [linux-boot](https://github.com/BunnyMaster/linux-boot) 为准
> - 本文说明环境：Kubuntu / Ubuntu + Docker；素材来自 [Release](https://github.com/BunnyMaster/auth-server/releases)
> - 本文只搭**基础中间件与初始化**；本机起前后端容器见 [[本地容器部署]]

## 本地启动前后端

### 项目下载

从 Github 中 Clone 两个项目：

```bash
git clone https://github.com/BunnyMaster/auth-web.git
git clone https://github.com/BunnyMaster/auth-server.git
```


### 项目安装

下载完成后前端使用 `pnpm i` 进行安装，后端自己配置 Java 环境进行基础依赖的下载。

```bash
# 后端
mvn complie
# 或mvn install 

# 前端
pnpm i
```
