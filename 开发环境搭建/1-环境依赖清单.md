## 环境依赖清单

> 本文只回答「要装什么」：版本结论与中间件清单。装机、compose、库表与启动步骤见同目录其它文档。
> 适用仓库：`auth-server`（后端）、`auth-web`（前端）

### 1. 本机工具

| 软件 | 推荐版本 | 用途 |
| ---- | -------- | ---- |
| **JDK** | **17** | 编译与运行 Spring Boot 微服务 |
| **Apache Maven** | **3.9.x** | 后端构建 |
| **Node.js** | **22**（最低 20.19）| 前端运行时 |
| **pnpm** | **≥ 9** | 前端包管理 |
| **Docker + Compose** | 当前稳定版 | 起中间件；可选容器化跑服务 |

系统与 Docker 装机见 [[2-系统环境]]（以 [linux-boot](https://github.com/BunnyMaster/linux-boot) 为准）。本机源码起前后端见 [[8-本地启动前后端]]。

### 2. 中间件

本地跑通需要下面四件套（用途即可，怎么起见 [[3-中间件-Compose]]）：

| 组件 | 用途 |
| ---- | ---- |
| **MySQL** | 业务库 + Nacos 持久化库 |
| **Redis** | 验证码、限流、会话等 |
| **Nacos** | 配置中心 + 服务发现 |
| **MinIO** | 本地对象存储；可与阿里云 OSS 切换 |

### 3. 可选外部依赖

不配则对应能力不可用（或关掉渠道开关）。密钥建议放 env，勿塞进 Nacos。

| 能力 | 依赖 |
| ---- | ---- |
| 邮件发送 | SMTP（如 QQ 邮箱 + 授权码）|
| 短信 | 阿里云 DYPNS |
| 钉钉工作通知 | 钉钉开放平台应用 |
| 对象存储（非 MinIO）| 阿里云 OSS AccessKey |
