## 系统环境

> [!IMPORTANT]
>
> - 系统装机与版本支持以 [linux-boot](https://github.com/BunnyMaster/linux-boot) 为准（Linux 系）；本文不重复长篇装机步骤
> - 本文说明环境：Kubuntu / Ubuntu + Docker
> - 中间件与业务素材来自 [auth-server Releases](https://github.com/BunnyMaster/auth-server/releases)

### 目标

本机具备可运行 Docker Compose 的基础环境（`docker` / `docker compose` 可用）。JDK、Maven、Node、pnpm 版本见 [[1-环境依赖清单]]；可用 linux-boot 对应阶段一并装上。

### 装机

按 [linux-boot](https://github.com/BunnyMaster/linux-boot) 的 profile / 阶段执行即可。开发机常见：Docker（阶段 04）+ 按需 Java / Node（06、07）。

### 验收

```bash
docker version
docker compose version
```

两条都能正常输出版本即过。
