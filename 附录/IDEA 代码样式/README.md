## IntelliJ 代码样式（不是 Auth 项目规范）


> [!NOTE]
> 本目录有一份 Spring Boot / Java 的 IDEA 格式化方案（`Intellij_Spring_Boot_Java_Conventions.xml`），**不是 Auth 项目规范**。


导入：

1. `Ctrl+Alt+S` 打开设置
2. Editor → Code Style → 齿轮 → Import Scheme → IntelliJ IDEA code style XML
3. 选本目录下的 xml，确认
